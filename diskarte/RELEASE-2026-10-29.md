# Release 2026-10-29

## Apply before using the new features

Run these in the Supabase SQL Editor, in order (the app keeps working without them; the new
features just stay hidden or show a "couldn't" toast):

1. `supabase/migrations/20261029000000_profile_connections.sql` — favourites, status expiry, profile connections
2. `supabase/migrations/20261029010000_scheduled_messages.sql` — scheduled messages, `tick_platform()`
3. `supabase/migrations/20261029020000_community_levels.sql` — levels / leaderboard
4. `supabase/migrations/20261029030000_channel_webhooks.sql` — incoming webhooks
5. `supabase/migrations/20261029040000_welcome_messages.sql` — welcome messages

Optional but recommended: `docs/sql/enable-platform-jobs.sql` (pg_cron, every minute). Without it,
scheduled messages only go out while their author has Diskarte open, and expired custom statuses
of people who are offline stay until they come back.

## Behaviour notes

- Scheduled messages are text-only, server text channels only (not DMs). A message that can't be
  sent at its time (timed out, slow mode, lost access, auto-mod) stays in the list with the reason.
- Read receipts use read positions DM participants could already see; there is no opt-out yet.
- Webhook messages can't ping @everyone/@here; webhook URLs are shown once — rotate if leaked.
- Levels are off by default for every Tambayan.
