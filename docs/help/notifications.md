# Notification issues

## I don't get any notifications

Work through these in order:

1. **Is the Tambayan or channel muted?** Open the Tambayan's menu → Notification Settings, and check
   whether a channel shows as muted.
2. **Quiet hours or a pause?** **Settings → Notifications**: quiet hours and **Pause for 1 hour**
   silence sounds, rings and alerts.
3. **Browser permission.** If you blocked notifications for Diskarte, allow them again in the browser's
   site settings, then turn them back on in Diskarte.
4. **Push for this device.** To get alerts while Diskarte is closed, turn on **This device** in
   **Settings → Notifications** and pick the kinds you want. If it says push isn't set up, the
   Diskarte server you use hasn't enabled background notifications yet.
5. **Your phone's settings.** Focus modes, Do Not Disturb and battery savers can delay or hide
   notifications.

## iPhone and iPad

Notifications only work when Diskarte is **installed to the Home Screen** (iOS 16.4 or newer):

1. Open Diskarte in Safari → **Share** → **Add to Home Screen**.
2. Open Diskarte from the Home Screen icon.
3. **Settings → Notifications** → turn on **This device** and allow notifications when asked.

## Notifications only say "Diskarte"

That's the private default: the lock screen doesn't show who wrote or what. Turn on **previews** in
**Settings → Notifications** if you want them.

## I get notified about something I already read

Read state syncs across devices, so this should be rare. If a device was closed while you read
elsewhere, its badge can stay until it next receives something or you open it.

## Too many notifications

- Set busy Tambayans to **Only @mentions** or **Nothing**.
- **Mute Channel** on noisy channels.
- Turn off categories you don't need under **This device**.
- Use quiet hours at night.

See also [Notifications, privacy and safety](../user-guide/notifications-and-privacy.md).
