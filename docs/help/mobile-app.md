# Mobile app (PWA) issues

Diskarte installs from the browser as a progressive web app — no app store.

## I can't find "Install"

| Device | Where |
| --- | --- |
| iPhone / iPad | Safari → **Share** → **Add to Home Screen** (other iOS browsers may not offer it) |
| Android | Chrome → **⋮** → **Install app** or **Add to Home screen** |
| Computer | The install icon in Chrome or Edge's address bar, or **Settings → Storage & Data → Install Diskarte** |

## The app looks out of date

Open **Settings → Storage & Data**. If an update is ready, press **Reload to update** (finish any call first). Your drafts and unsent messages are kept.

## The app is acting strangely

**Settings → Storage & Data → Clear downloaded app files** removes the cached app files and downloads
fresh ones. Drafts and waiting messages stay.

## The keyboard covers the message box

Diskarte resizes itself when the on-screen keyboard opens. If something still looks off, rotate the
phone or close and reopen the keyboard; then [report it](report-a-problem.md) with your phone model.

## No notifications on iPhone

Notifications need the Home Screen app on iOS 16.4 or newer. See
[Notification issues](notifications.md#iphone-and-ipad).

## Calls stop when I switch apps

Phones may pause audio for web apps in the background, depending on the browser and battery
settings. Keep Diskarte open during important calls.

## I'm offline

You'll see an offline page if you open Diskarte without a connection, and messages you send wait
until you're back online. Conversations you haven't loaded aren't available offline.
