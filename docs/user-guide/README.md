# Diskarte user guide

Plain-language help for using Diskarte. No technical knowledge needed.

| Guide | You'll learn to |
| --- | --- |
| [Getting started](getting-started.md) | Create an account, install Diskarte on your phone or computer, set up your profile |
| [Tambayans](tambayans.md) | Create a Tambayan, invite friends, set up channels and run your community |
| [Messages](messages.md) | Send messages, photos and voice notes, reply, react, search, schedule messages |
| [Calls](calls.md) | Join voice channels, call friends, share your screen |
| [Events and Moments](events-and-moments.md) | Schedule events, RSVP, and share 24-hour Moments |
| [Shared workspace](workspace.md) | Keep notes, task boards, focus timers, links and a whiteboard with your group |
| [Notifications, privacy and safety](notifications-and-privacy.md) | Control alerts, choose who can add you, block people, protect your account, download or delete your data |

**Words you'll see**

- **Tambayan** — a community (like a server or group). You can be in up to 100.
- **Channel** — a room inside a Tambayan: text (#), voice (speaker icon) or forum.
- **Diskarte HQ** — the official Tambayan everyone is in, for announcements.
- **DM** — a direct message between you and friends.
- **Moderator / Admin / Owner** — people who help run a Tambayan.

Something not working? Settings → **Report a problem** sends a note to the Diskarte team.
