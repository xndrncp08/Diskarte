# Shared workspace

Every Tambayan has a **workspace** for planning and studying together. Open it from the Tambayan's
menu or channel list. Everything belongs to a text channel, and anyone who can see that channel can
see its documents.

| Tool | Good for |
| --- | --- |
| **Note** | Meeting notes, reviewers, guides (Markdown) |
| **Task board** | To do / Doing / Done cards for a project or event |
| **Focus timer** | A shared study or work session (1–120 minutes) everyone counts down together |
| **Resources** | A list of useful links (https only) with descriptions |
| **Whiteboard** | Quick sketches and diagrams |

**Editing together:** when two people change the same document, Diskarte doesn't silently overwrite
anyone. If someone saved while you were editing, you'll see their version and choose whether to keep
yours or theirs. Your unsaved text stays until you decide.

**Can't edit?** You might be timed out, the channel might be read-only, or it might require a
verified email. On phones, editors open full screen; leaving with unsaved changes asks first.
