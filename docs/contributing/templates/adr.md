# Architecture decision record template

Append a new section to [`docs/architecture/decisions.md`](../../architecture/decisions.md) and add a
row to its index table. Number sequentially; never renumber. If a decision is replaced, keep the old
record, set its status to "Superseded by NNN" and link the new one.

---

## NNN. <Short decision title>

**Status.** Proposed / Accepted / Superseded by NNN — *YYYY-MM-DD*

**Context.** The problem and the forces at play (constraints, incidents, costs). Link to code,
issues or release notes.

**Decision.** What we do, stated plainly.

**Alternatives considered.** Each with the reason it lost.

**Consequences.** What gets easier, what gets harder, what must now be true for contributors
(rules, tests, operational steps).
